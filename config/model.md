# X-Former 模型流程

## 一句话

患者的三类数据（脑影像 + 临床指标 + 灌注放射组学）各自编码成 token，拼在一起通过**信息瓶颈**筛选关键信号，最后输出"预后良好 vs 预后不良"的预测概率。

---

## 输入：一个患者的三类数据

```
┌─────────────────────────────────────────────────────┐
│ 患者输入                                              │
├──────────────┬──────────────────┬───────────────────┤
│ 脑影像        │ 临床指标          │ 灌注放射组学        │
│ (MRI 或 CT)  │ (年龄、性别、NIHSS…)│ (脑血流时间序列)    │
│ [3, 64,160,160] │ [F] F=15~24      │ [T, 16] T=41~51    │
└──────────────┴──────────────────┴───────────────────┘
```

- **脑影像**：3 通道 3D 体数据（3 个窗宽窗位归一化后的 CT/MRI 图像，统一缩放到 64×160×160）
- **临床指标**：一维向量，15-24 个特征（两个数据集特征数不同，自动补零对齐）
- **灌注放射组学**：时间序列矩阵，每行是一个时间点，每列是一个纹理特征

---

## 第一步：编码 → Token

三类数据分别被**编码器**压缩成固定数量的向量（token），统一投影到 256 维：

```
  脑影像 [3,64,160,160]                      临床 [15]                      放射组学 [51,16]
       │                                          │                               │
       ▼                                          ▼                               ▼
  Swin-UNETR                                 原型编码器                        数据集投影
  (3D 视觉主干)                            (M=8 个可学习原型                    + 时序 Transformer
       │                                  关注所有临床特征)                         │
       ▼                                          │                               ▼
  [512,4,10,10]                               [8, 128]                         [1, 128]
       │                                          │                               │
       ▼                                          ▼                               ▼
  Perceiver 压缩                            投影 → 256                       投影 → 256
  (K=32 个查询向量                              │                               │
   交叉注意特征图)                               ▼                               ▼
       │                                   [8, 256]                         [1, 256]
       ▼
  [32, 256]
```

**关键设计：**
- Swin-UNETR 的底层（patch_embed + layers1-2）冻结，只微调高层 layers3-4
- 原型编码器用 M=8 个可学习向量查询所有临床特征，缺失特征自动被注意力忽略
- 放射组学的投影层按数据集区分（77sets=16 维，ISLE=15 维），共享同一个时序 Transformer

---

## 第二步：拼接 → 瓶颈融合（核心创新）

所有 token 拼成一个大序列，送入 4 层信息瓶颈：

```
  [32, 256] + [8, 256] + [1, 256] = [41, 256]          ← 总共 41 个 token
       │
       ▼
  ╔═══════════════════════════════════════╗
  ║         信息瓶颈 × 4 层               ║
  ║                                       ║
  ║  每层做三件事：                        ║
  ║  ① 所有 token 自注意（互相看）         ║
  ║  ② 压缩：41 token → 8 个槽位          ║
  ║  ③ 扩展：8 槽位 → 41 token            ║
  ╚═══════════════════════════════════════╝
       │
       ▼
  [8, 256]   ← 最终瓶颈特征
```

**为什么叫"信息瓶颈"？** 就像把三页纸的摘要压缩成八个关键词 —— 如果不相关信息太多，槽位装不下，网络被迫只保留对预测最重要的信号。三种模态争夺这 8 个槽位，天然实现了模态间的信息筛选和跨模态对齐。

---

## 第三步：分类 + 域对抗

瓶颈特征平铺后分两路：

```
         [8, 256] → flatten → [2048]
              │
     ┌────────┴────────┐
     ▼                 ▼
  分类头             域分类器
  MLP(2048→256       (带梯度反转层)
   →128→2)               │
     │                   ▼
     ▼               [2] → 预测这是 MRI 还是 CT
  [2] → softmax
     │
     ▼
  预后良好 / 预后不良
```

- **分类头**：标准 MLP，输出二分类 logits
- **域分类器**：前面有一个**梯度反转层（GRL）**——正向传播不变，反向传播时梯度取反。这意味着模型越想区分 MRI/CT，梯度越反向惩罚。最终迫使瓶颈特征**无法区分**数据来源，实现模态无关。

---

## 损失函数

| 损失 | 作用 | 当前权重 |
|------|------|----------|
| Focal Loss | 主分类损失，关注难分样本 | 1.0 |
| 域对抗损失 | 惩罚模型区分 MRI/CT，促进模态无关 | 0.05 |
| 对比损失 | 同类（同预后）样本特征拉近，异类推远 | 0.03 |
| 一致性损失 | ISLE 有/无病灶特征的两组预测应一致 | 0.05（当前关闭） |

## 完整前向流程（代码视角）

```python
# 1. 编码
img_tokens  = ImageEncoder(image)           # [B, 32, 256]
cli_tokens  = ClinicalEncoder(clinical)      # [B, 8,  256]
rad_token   = RadiomicsEncoder(radiomics)    # [B, 1,  256]

# 2. 拼接
tokens = concat([img_tokens, cli_tokens, rad_token])  # [B, 41, 256]

# 3. 瓶颈
bottleneck = BottleneckFusion(tokens)       # [B, 8, 256]
flat = bottleneck.flatten()                  # [B, 2048]

# 4. 预测 + 域判断
logits       = Classifier(flat)              # [B, 2]
domain_logits = DomainHead(GRL(flat))        # [B, 2]
```

## 数据流维度汇总

| 阶段 | 输入形状 | 输出形状 | 参数量 |
|------|---------|---------|--------|
| 图像编码 (Swin+Perceiver) | [B, 3, 64, 160, 160] | [B, 32, 256] | ~20M (冻结 ~15M) |
| 临床编码 (原型) | [B, F] | [B, 8, 256] | ~0.1M |
| 放射组学编码 | [B, T, 16] | [B, 1, 256] | ~0.3M |
| 瓶颈融合 | [B, 41, 256] | [B, 8, 256] | ~4M |
| 分类头 | [B, 2048] | [B, 2] | ~0.5M |
| **总计** | | | **~10M 可训练** |
